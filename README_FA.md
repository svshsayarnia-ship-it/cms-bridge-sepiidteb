# سپید بیوتی CMS Bridge

این نسخه برای اتصال سایت سپید بیوتی به GitHub و Vercel آماده شده است. سایت با Next.js اجرا می‌شود و پنل `/cms` برای مدیریت محصولات ووکامرس، تصاویر، قیمت، موجودی، توضیحات کوتاه و توضیحات کامل ساخته شده است.

## نکات مهم

- صفحه اصلی شامل نسخه پریمیوم با hover، animation و صحنه pseudo-3D است.
- کارت‌های محصول، مسیر انتخاب و بخش CMS با زبان بصری نسخه کامل هماهنگ شده‌اند.
- برای Vercel از `npm run build` استفاده شود.
- متغیرهای `.env.example` را در Vercel وارد کن و مقدارهای واقعی WooCommerce را فقط در Environment Variables نگه دار.
